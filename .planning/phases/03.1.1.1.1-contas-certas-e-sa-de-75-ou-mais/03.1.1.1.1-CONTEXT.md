## Locked decisions
- **D-01 (João approved, 12/11):** the "funil fora de ordem" gate no longer blanks the whole screen. It blocks only the conclusion involving the inconsistent stage; consistent stages still give the verdict and rings; the inconsistent stage becomes a team finding ("conferir a marcação no CRM"). Partial measurement shows as a caveat ("medido em N de M dias"), not "Sem dado".
- **D-02:** never compare clinics with each other on clinic-facing screens.
- **D-03:** SQL that writes, migrations and RPC changes are run only by João. Plans deliver ready SQL files and say so. We only run read-only SELECT on production. Never impersonate an admin (no JWT-claim tricks).
- **D-04:** the health score must not punish a working connection for a business state. An ads account that Meta stopped delivering (spend limit, payment, missing WhatsApp) while reads succeed is a client alert ("Quem resolve: Cliente"), not a stopped source.
- **D-05:** honesty rules stay: only measured data, "Falta dado" with reason, no invented numbers, rules only.
</decisions>
