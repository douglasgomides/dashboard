## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Bloqueio] Build precisa das variáveis do Supabase falso**
- **Found during:** Task 2, primeira rodada do e2e
- **Issue:** `npm run build` sem `VITE_SUPABASE_URL` e `VITE_SUPABASE_PUBLISHABLE_KEY` embute "Supabase não configurado" no bundle; com `PLAYWRIGHT_SKIP_BUILD=1` o preview serve esse bundle e todos os testes falham. O `env` do webServer só vale para o preview, não para o build.
- **Fix:** o build do e2e foi feito com `VITE_SUPABASE_URL=http://localhost:9 VITE_SUPABASE_PUBLISHABLE_KEY=fake-public-test-key npm run build`. Nenhum arquivo mudou por isso; vale para quem rodar o comando de verify do plano.
