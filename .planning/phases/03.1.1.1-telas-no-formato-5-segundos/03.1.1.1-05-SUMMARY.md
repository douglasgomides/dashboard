## Deviations from Plan

### Plan interpretation choices

**1. "Ver quem está esperando" opens the leads list, not a list of the waiting people.** The plan says "the leads list when listas has it". The app has no list of "virou lead and nobody attended"; the list it opens (Pessoas novas) includes the attended ones. The button text is the pilot's. Question for João below.

**2. The verdict example in the plan (Virou lead -> Atendido, 10%) cannot happen in the real funnel.** `dePacientesDoPeriodo` gives that link no % (Atendido includes old patients), so `maiorPerda` is only Atendido->Agendou or Agendou->Fechou. `vereditoDePacientes` supports all four stage words and the unit test covers the 10% case with a hand-built funnel.

**3. Task 1 already moved the 4 old person cards into "Ver tudo"** (the plan did it in task 2) so the tracer commit passes its own height checks.

**4. The CSS compression sheet is in the task 3 commit,** so the task 2 commit alone is over the height limit (only task 1 and the final state are measured).

**5. NxSelo "Em alta/Em queda" is not repeated on the cards** when the pill already carries sign and word; "Fora do normal" is not built (no own-normal band on this screen). Same call as plan 03.

**6. Mobile hides the impacto chip of a finding, the page meta line (decision tag and period) and the funnel card title.** All came from the height ruler; the number in jogo is still in the "Por quê?" bars and the chip's `title`. The period is in the shell's period selector.

**7. "Agendam de cada 100 leads" has no 30-day line** (the daily series is of counts, not of the rate), only Fecharam has it.

**8. Specs beyond the plan's list.** `telas-juntadas.spec` needed a second edit (the D-07 loop at line 820 also reads `/pacientes`); `resultados-painel` and `comercial-painel` follow the new order (Ver tudo opened before the reading, old cards and pizza inside it). The test titles of the first still say "com leitura" for the new entry.
