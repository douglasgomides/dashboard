# Phase 03.1.1.1.1.1 Plan 05: One attendance rule in the CRM guide Summary

The CRM guide now uses the same attendance rule as the database. `RE_COMPARECEU` and `RE_NAO_COMPARECEU` are exported from `src/lib/guia-crm.ts`, and the 'realizada' role is "matches RE_COMPARECEU and not RE_NAO_COMPARECEU". The bare `realizad` is gone, so "Contato realizado" no longer counts as attendance.

## What changed

- `src/lib/guia-crm.ts`: the two regexes are exported with the comment "Copiado literalmente no SQL (plano 08); mudar os dois juntos". They are taken verbatim from RESEARCH Achado 4. The 'realizada' rule is now the predicate `compareceu`. The order of REGRAS is the same as before: perdido, ganho, reativacao (no-show), realizada, and so on. `papelDaEtapaComPerfil` is unchanged, so the clinic profile still wins over the name.
- `scripts/test-guia-crm.ts`: adds generic stage names from the RESEARCH table that should count as attended and names that should not, each with its expected role. It also checks that both exported regexes are case-insensitive.

## Changed assertions in test-guia-crm.ts (fixed by this rule)

| Name | Before | Now |
|---|---|---|
| "Reunião realizada" | realizada | desconhecida (moved to the not-attended list) |
| "Pos-procedimento" | pos | realizada (moved to the attended list). In the `casos` table it was replaced by "Pós Venda" -> pos. |

All other existing assertions are unchanged.
